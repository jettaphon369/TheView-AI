สิ่งที่เพิ่ม
- เพิ่มตัวเลือก “1 สินค้า / หลายสินค้า” ในหน้าสร้างสินค้า
- โหมดหลายสินค้าเพิ่มได้สูงสุด 50 รายการต่อครั้ง
- ใช้กลุ่มสต๊อก / พื้นที่สต๊อกร่วมกันสำหรับชุดที่เพิ่ม
- แต่ละสินค้ากำหนดชื่อ, SKU, หมวดหมู่, หน่วย, จำนวนเริ่มต้น, จุดเตือนต่ำ และวันหมดอายุได้
- ตรวจชื่อซ้ำในฐานข้อมูลและในชุดเดียวกัน
- ตรวจ SKU ซ้ำทั้งหน้าเว็บและ Firebase SKU Registry ก่อนเขียน
- แสดง error ที่การ์ดสินค้าที่มีปัญหา
- มีหน้าต่างยืนยันสรุปจำนวน/พื้นที่/ชื่อก่อนบันทึก
- บันทึกสินค้า + SKU Registry + Log/Audit สรุปทั้งชุดแบบ Firestore transaction เดียว (Atomic)
- โหมดหลายสินค้าไม่อัปโหลดรูปพร้อมกัน เพื่อลดความเสี่ยงบนมือถือ; เพิ่มรูปภายหลังได้
- Cache/Service Worker bump เป็น v34.29.52

ความปลอดภัย
- MAIN ยังคงล็อก Firebase ที่ theview-4d389
- ไม่แก้ Firestore rules หรือ Storage rules
