- main.css

ฟังก์ชันที่เพิ่ม
1. เลือกว่าสินค้ามีหรือไม่มีวันหมดอายุ
2. ระบุวันหมดอายุ
3. แจ้งเตือนล่วงหน้า 3 / 7 / 14 / 30 วัน หรือกำหนดเอง
4. Dashboard แยกสต๊อกใกล้หมดและสินค้าใกล้หมดอายุ
5. ตัวกรองสินค้าใกล้หมดอายุ เรียงวันที่ใกล้ที่สุดก่อน
6. Badge สถานะบนการ์ดสินค้าและรายละเอียดสินค้า
7. เตือนก่อนส่งคำขอเบิกสินค้าที่หมดอายุหรือหมดอายุวันนี้
8. แสดงคำเตือนในหน้าตรวจอนุมัติรายการเบิก
9. เพิ่มเหตุผลปรับยอด: ของเสีย, หมดอายุ, แตกหัก/ชำรุด, สูญหาย, ใช้ภายใน
10. Firestore รองรับฟิลด์ hasExpiry, expiryDate, expiryReminderDays

ความเข้ากันได้
- สินค้าเดิมที่ไม่มีฟิลด์ใหม่จะถือว่าไม่มีวันหมดอายุ
- รองรับการอ่านฟิลด์เก่า expiryAlertDays เพื่อความเข้ากันได้ แต่ข้อมูลใหม่จะบันทึกเป็น expiryReminderDays
- ยังไม่มีระบบ Lot / FEFO ใน Phase 1
